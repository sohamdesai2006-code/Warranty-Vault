# 🛡️ Warranty Vault

A secure, modern web application designed to help users track product warranties, manage purchase receipts, and stay organized. Never let a warranty expire in silence again.

👉 **[Live Demo](https://warranty-vault-orpin.vercel.app)**

---

## 🚀 Key Features

* **One-Click Google Authentication:** Seamless and secure access to your personal vault with a single click. There is no need to manually type, manage, or remember complex email and password credentials.
* **AI Receipt Scanning:** Powered by Google's **Gemini 2.5 Flash**, the app automatically extracts product names, purchase dates, and warranty durations directly from uploaded receipt images to auto-fill forms.
* **Camera Capture:** Scan physical receipts instantly using your device's built-in camera with auto-fill support.
* **Device-Bound Security PIN:** Keep your data safe with a local security lock that secures your vault instantly whenever you switch browser tabs.
* **Interactive Dashboard:** Fast instant search, category filtering, light & dark theme toggling, and archived status tracking.

---

## 🛠️ Tech Stack

* **Frontend:** Next.js (React), Tailwind CSS
* **Database & Auth:** Supabase (PostgreSQL, OAuth)
* **AI Integration:** Google Gen AI (Gemini API)
* **Hosting:** Vercel

## 💻 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/sohamdesai2006-code/Warranty-Vault.git
cd Warranty-Vault
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
